# تأسيس — Web App

## الملفات
- `index.html` التطبيق كامل (الحروف، الحركات، التلبيس، الخريطة).
- `games.js` ألعاب الحروف كلها، تتحمل بس أول ما الطفل يفتح لعبة.
- `chars/` صور الشخصيات والملابس (كل صورة تتحمل لما تنفتح شاشتها).
- `art/` رسومات الألعاب (Gemini، خلفية شفافة). القائمة بأسمائها في `art/catalog.json`، وتنفع لأي لعبة جديدة.
- ركن الأهل في الشاشة الأولى: تقرير أسبوعي محفوظ على نفس الجهاز بس.
- `audio/` أصوات الحروف والحركات (ElevenLabs) لما تنضاف:
  - `audio/letters/<id>.mp3` اسم الحرف
  - `audio/v/<id>-f.mp3` و `-d` و `-k` الفتحة والضمة والكسرة
- `manifest.webmanifest` و `sw.js` و `icons/` عشان ينضاف للشاشة الرئيسية ويشتغل بدون نت.

## الرفع على GitHub Pages
1. في GitHub: New repository، الاسم `taasees`، Public.
2. Add file ← Upload files، وارفعي كل الملفات والمجلدات اللي هنا مثل ما هي.
3. Settings ← Pages ← Branch: `main` ← Save.
4. بعد دقيقة يصير الرابط: `https://اسمك.github.io/taasees/`
5. افتحيه من الجوال ← مشاركة ← "إضافة إلى الشاشة الرئيسية".
